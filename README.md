# bNIRS–EEG Optode Coupler

## Overview

This repository contains the 3D-printable design file for a bNIRS–EEG optode coupler, developed to support the positioning of bNIRS optodes during simultaneous bNIRS and EEG data acquisition.

The design is provided as an STL file, allowing researchers to download, view and print the coupler using standard 3D-printing software.

## Repository contents

| File | Description |
|---|---|
| `NIRS_EEG_optode_coupler.stl` | 3D model of the bNIRS–EEG optode coupler, provided in STL format for 3D printing. |

## 3D Printing

To use the design:

1. Download `NIRS_EEG_optode_coupler.stl` from this repository.
2. Open the STL file in your preferred 3D-printing slicer software.
3. Check the model dimensions and compatibility with your optode hardware and headgear.
4. Configure the printing settings according to your printer and material.
5. Export the sliced model and print.

Researchers should check the dimensions and fit of the printed component against their specific hardware before use.

## Intended Use

The optode coupler is intended to support optode positioning during bNIRS data acquisition in setups combining bNIRS and EEG.

The design is shared to facilitate the reproducibility and adaptation of experimental equipment used in multimodal neuroimaging research.
