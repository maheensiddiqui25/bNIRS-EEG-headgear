# bNIRS-EEG-headgear
bNIRS-EEG headgear optode couplers 

This repository contains the STL file for a 3D-printable optode coupler. 

## Files

- `optode_coupler.stl` — 3D model for printing.

## 3D Printing

Download the STL file and open it in your preferred 3D-printing slicer software. Check the model dimensions and compatibility with your hardware before printing.

## Intended Use

This component is intended to support optode positioning during bNIRS data acquisition.
